Aplikasi Buku Harian ini dikembangkan menggunakan React Native dengan Expo CLI sesuai panduan modul praktikum Mobile Programming, yang menampilkan daftar entri jurnal secara dinamis memanfaatkan komponen dasar seperti ScrollView, View, Text, dan Image. Seluruh kartu entri disusun secara rapi menggunakan Flexbox dan disesuaikan dengan konsep reusable component (DiaryCard), di mana setiap entri memuat foto profil/momen, judul aktivitas, tanggal pencatatan, serta ringkasan cerita harian

langkah menjalankan proyek:
- Buka Terminal & Masuk ke Folder Proyek
- Ketik perintah berikut untuk memulai server Metro Expo: npx expo start
- Buka Aplikasi di Device Smartphone Fisik (Expo Go): Buka aplikasi Expo Go di HP lalu Scan QR Code yang muncul di terminal.

fitur yang di selesaikan:
- menambahkan dua entri baru sehingga total ada lima entri.
- mengganti tiga gambar remote dengan gambar lokal pada folder assets/moods. 
- menambahkan avatar pengguna pada header menggunakan Image. 
- membuat variasi border atau tampilan kartu berdasarkan mood.
